This is a demonstration, not a benchmark. The CPU side is plain JavaScript (one Web Worker per core); the GPU side is a WebGPU compute kernel with one thread per pixel, timed after a warm-up launch (best of three). Auto size picks the largest image for which one CPU core takes about two seconds on this device. At tiny sizes, all cores are barely faster than one: with too little work, coordination overhead dominates. WebGPU has no 64-bit floats, so the GPU computes in FP32 while JavaScript uses FP64; press Deep zoom and compare the CPU and GPU images. Phones may throttle when hot or in low-power mode.
